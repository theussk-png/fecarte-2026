# Fecarte 2026

* Projeto criado por estudantes do 2DS durante a preparação para a Fecarte 2026 na Etec Abdias do Nascimento, conta a história do cinema por meio de jogos que retratam filmes de terror;
* Jogos Mortais, Pânico, Telefone Preto e Sexta-Feira 13.

# Linguagens usadas

* **HTML5 / CSS3 / JavaScript**
